# The C Calculator

A C based CLI calculator with 7 operations(sqrt and power using math.h library)

<img width="1108" height="181" alt="image" src="https://github.com/user-attachments/assets/93b5538f-60eb-4207-98c6-6e3ba0e0a935" />

Perform operations using 2 different numbers such as addition(+),subtraction(-),multiplication(*),division(/),remainder(%),square root(sqrt), power(pow,^).

If you wish to test the source code please make sure you have gcc already installed, otherwise you can test it using the exe provided.
